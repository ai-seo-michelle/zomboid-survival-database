# Zomboid Survival Database

A lightweight Project Zomboid survival database site built with Astro and Tailwind CSS.

## Stack

- Astro
- Tailwind CSS
- Static output for Cloudflare Pages

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Cloudflare Pages settings:

- Build command: `npm run build`
- Output directory: `dist`
- Node version: `22`

Set `PUBLIC_SITE_URL` in Cloudflare Pages when the production domain is ready.
